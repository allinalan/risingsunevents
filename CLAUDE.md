# risingsunevents.net — RSD Events Team website

Built 2026-11-17 to replace the Squarespace site (Alan: "Build my own site", all defaults). Public repo
`allinalan/risingsunevents`, GitHub Pages from `main` `/docs`. Read README.md for how to change anything.

- **Source of truth:** `content/*.md` (one file per page, front matter `title`, `nav`, `old`), `data/links.json`,
  `data/dates.json`, `data/site.json`, `assets/`. `docs/` is generated by `node build.js`; never hand-edit it.
- **Fail closed:** `node build.js --check` (exit 1, `BUILD PROBLEM:` lines) must pass before a push. Every old
  Squarespace address keeps working (`old:` in front matter → a redirect page; `/new-events/*` and `/s/*` are
  handled in `404.html`).
- **Who writes here:** the webmaster agent (rsd-shift-picking `webmaster.js`, `com.rsd.webmaster.tick`, #rsd-website)
  on Alan's typed approve, from the mini's checkout `~/automations/risingsunevents`; and people, through PRs or plain
  pushes. The agent starts every publish from what GitHub has (fetch + reset to origin/main) and pushes plainly; never
  force-push.
- **Readers:** reps (the site), SUNNY (`dates.json`, once `SUNNY_DATES_SOURCE=site`), the webmaster's read-back
  (`build.json` fingerprint).
- **Domain:** `data/site.json` `cname` is null while staging at allinalan.github.io/risingsunevents. The cutover sets it
  to `www.risingsunevents.net` (docs/CUTOVER.md); the DNS records at Squarespace Domains are Alan's step.
- Arizona time everywhere (`-07:00`, no daylight saving). Phone numbers on /join are the ones the old site already
  published; do not add more personal details.
